# Together for Thalassemia — Website

A responsive static website for the student-led O-Level Global Perspectives initiative at SICAS JT, Lahore.

## Included
- `index.html` — main website and clearly marked editable event/content areas
- `styles.css` — design and responsive layout
- `script.js` — mobile menu, reveal animations and contact-form validation
- `assets/logo.jpeg` — supplied Together for Thalassemia logo
- `assets/alkhidmat-visit-1.jpeg` — supplied visit photograph
- `assets/alkhidmat-visit-2.jpeg` — supplied visit photograph

## How to edit events
Open `index.html` and search for `EDIT EVENTS HERE`.

To add an event, duplicate an `.event-card` and change:
- title
- description
- date/location
- image filename
- small category label

Put new photographs inside `assets/` and reference them like `assets/my-photo.jpeg`.

## Other easy edits
Search `EMAIL ADDRESS`, `INSTAGRAM HANDLE`, `Date to be added`, `Add date`, and `00` to update placeholders.

## Hosting
This is a plain HTML/CSS/JS static site and can be hosted on GitHub Pages, Cloudflare Pages, Netlify, or another static host. HTTPS should be enabled by the hosting provider.

## Important accuracy rule
Do not add patient numbers, medical claims, partnerships, awards, fundraising totals, testimonials, or impact figures unless they are real and verified by the team.

## Contact form
The form is intentionally not connected to a backend. Before using it publicly, connect it to a secure form service or backend and update the form accordingly.
